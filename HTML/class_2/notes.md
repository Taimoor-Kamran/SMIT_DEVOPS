1. <abbr> = Abbreviation

Short form show karta hai.

<abbr title="Hyper Text Markup Language">HTML</abbr>

👉 Mouse hover karne par full form show hogi.

2. <cite> = Citation / Source Name

Book, movie, website, article ka naam show karne ke liye.

<cite>Harry Potter</cite>

👉 Mostly italic text hota hai.

3. <dfn> = Definition Term

Jab kisi word ko define karna ho.

<dfn>HTML</dfn> is markup language.

👉 Yeh batata hai ke yeh term define ho rahi hai.

4. <address> = Contact Information

Author ya company ka address/contact.

<address>
Karachi Pakistan <br>
abc@gmail.com
</address>
5. <ins> = Inserted Text

New add text underline hota hai.

<p>Price <ins>500</ins></p>

👉 Underline text.

6. <del> = Deleted Text

Delete text strike line.

<p>Price <del>1000</del></p>

👉 Cross line.

7. <s> = No Longer Correct Text

Old price ya wrong text.

<p><s>1000</s> 500</p>

👉 Strike through.

📘 Lists
8. <ol> = Ordered List

Number list.

<ol>
<li>Tea</li>
<li>Coffee</li>
</ol>

Output:

Tea
Coffee
9. <ol type="">

Number style change.

<ol type="A">
<li>HTML</li>
<li>CSS</li>
</ol>

Types:

1 = 1,2,3
A = A,B,C
a = a,b,c
I = I,II,III
i = i,ii,iii
10. <li> = List Item

Har item list ka.

<li>Apple</li>
11. <ul> = Unordered List

Bullet list.

<ul>
<li>Apple</li>
<li>Mango</li>
</ul>
12. <ul style="list-style-type:;">

Bullet style change.

<ul style="list-style-type:square;">
<li>Apple</li>
<li>Mango</li>
</ul>

Types:

disc ●
circle ○
square ■
none
13. <dl> = Description List

Definition list.

<dl>
<dt>HTML</dt>
<dd>Markup Language</dd>
</dl>
14. <dt> = Definition Title

Heading / word

<dt>HTML</dt>
15. <dd> = Description Data

Definition detail.

<dd>Used for webpage structure</dd>
📘 Links
16. <a> = Anchor Tag

Link banane ke liye.

<a href="https://google.com">Google</a>
17. <a> with Unordered List

Menu banane ke liye.

<ul>
<li><a href="">Home</a></li>
<li><a href="">About</a></li>
</ul>
18. mailto

Email open karne ke liye.

<a href="mailto:test@gmail.com">Email Us</a>
19. target

New tab ya same tab.

<a href="https://google.com" target="_blank">Google</a>
Types:
_blank = new tab
_self = same tab
20. tel

Phone dial karne ke liye.

<a href="tel:+923001234567">Call Now</a>
📘 Images
21. <img>

Image show karne ke liye.

<img src="pic.jpg">
22. height width

Image size set.

<img src="pic.jpg" height="200" width="300">
23. align

Old method image align.

<img src="pic.jpg" align="right">

Types:

left
right
top
middle

⚠️ Modern HTML/CSS mein align outdated hai. CSS use hoti hai.
